06 · Performance rules — non-negotiable
NEVER
backdrop-filter or filter: blur(). Both re-rasterise on every scroll frame. This is what made the first glass draft lag.
LIMIT
One shadow per frame, none on cards, rows or chips. Depth comes from surface steps: canvas → card → inset.
ALWAYS
Opaque hex fills on anything that scrolls, gradients baked into the element, transitions only on opacity and transform.
